# 한 칸 탈출 · A LITTLE WAY OUT

아이폰의 세로 화면과 터치 드래그를 중심으로 만든 주차 퍼즐입니다.
빨간 차를 오른쪽 출구까지 이동시키세요. 차량은 길이 방향으로만 움직이며,
한 번에 여러 칸을 밀어도 1회 이동입니다.

## 게임 내용

입문 12개, 도전 12개, 고수 12개로 총 36개 스테이지가 있습니다.
최소 이동 횟수는 3~24회이며 모든 스테이지의 최단 해법을 검증했습니다.
현재 배치에서 다음 수를 찾는 힌트, 힌트 이동, 무제한 되돌리기,
다시 시작, 별 3개 도전, 최고 기록과 진행 상태 저장, 효과음이 포함됩니다.
스테이지는 모두 열려 있어 원하는 판부터 시작할 수 있습니다.

드래그 대신 차량을 탭하고 아래 방향 버튼으로도 조작할 수 있습니다.
키보드에서는 Tab으로 차량을 고른 뒤 방향키를 사용합니다.
방향 버튼은 한 번 누를 때마다 한 칸 이동하고 이동 횟수도 1회 늘어납니다.
여러 칸을 1회로 이동하려면 드래그하세요.
힌트는 별 점수에 영향을 주지 않습니다.

## 아이폰 사파리에서 실행

이 폴더는 웹에 아직 배포되지 않은 게임 원본입니다.
첨부 HTML을 아이폰의 파일 미리보기에서 여는 것만으로는 실행이 보장되지 않습니다.
사파리에서 사용할 웹주소를 만들려면 아래처럼 정적 웹 호스팅에 한 번 올리세요.

1. 배포용 ZIP 압축을 풉니다.
2. Netlify Drop에서 index.html이 바로 들어 있는 one-lane-escape 폴더를 업로드합니다.
3. 생성된 사이트 주소를 아이폰 사파리로 엽니다.
4. 사파리의 공유 메뉴에서 '홈 화면에 추가'를 선택합니다.
   '웹 앱으로 열기' 항목이 보이면 켠 뒤 추가합니다.

Netlify 연결을 통한 배포도 가능합니다. 공개 배포 전에 사이트 공개 범위를 확인하세요.
빌드 명령, Node.js, npm 패키지, 데이터베이스, API 키는 필요하지 않습니다.

공식 안내:
- Netlify 수동 배포: https://docs.netlify.com/deploy/create-deploys/#drag-and-drop
- Apple 웹 앱 추가: https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios

## 파일

- index.html: 게임 전체 코드, 화면, 스타일, 36개 퍼즐 및 힌트 탐색기
- manifest.webmanifest: 홈 화면 웹 앱 설정
- sw.js: HTTPS 배포 환경에서 사용하는 오프라인 캐시
- icon-180.png / icon-192.png / icon-512.png: 직접 제작한 앱 아이콘

별도로 제공한 one-lane-escape.html은 게임 코드가 모두 들어 있는 단일 파일 버전입니다.
일반 데스크톱 웹브라우저에서 로컬 파일로 열 수 있습니다.
아이폰에는 위의 웹 배포 방식을 권장합니다.

## 기록과 오프라인

기록은 해당 사이트의 localStorage에 저장하고 외부로 전송하지 않습니다.
같은 브라우저와 같은 사이트 주소 안에서 이어집니다. 다른 기기와 동기화하지 않습니다.
비공개 브라우징, 사이트 데이터 삭제, 운영체제의 저장 공간 정리 등에 따라
저장 데이터가 사라질 수 있습니다. 게임 계정이나 클라우드 백업은 없습니다.

배포용 폴더에는 오프라인 캐시 코드가 포함되어 있습니다.
HTTPS 주소에서 처음 접속해 캐시 설치가 성공하면 오프라인 재실행에 사용할 수 있습니다.
캐시가 제거되거나 설치되지 않은 상태에서는 다시 인터넷 연결이 필요합니다.
실제 아이폰 사파리에서의 홈 화면 설치와 오프라인 재실행은 별도 확인이 필요합니다.

## 검증 범위

- 36개 스테이지의 배치 유효성, 최단 해법과 표시된 최소 이동 횟수 일치 확인
- 36개 전체를 실제 게임 이동/충돌/승리 처리 코드로 완주
- Chromium 터치 에뮬레이션으로 첫 스테이지 3회 이동 클리어 및 별 3개 확인
- 막힌 방향, 차량의 수직 방향, 길게 밀기, 터치 취소 처리 확인
- 힌트, 힌트 이동, 되돌리기, 재시작 확인창, 스테이지 변경 확인창 검증
- 변경된 고수 스테이지에서의 힌트 및 Web Worker가 없는 경우의 대체 탐색 검증
- 저장/복원은 Web Storage 호환 테스트 저장소로 직렬화와 복원 로직 검증
- 320×568, 375×667, 390×844, 430×932, 844×390 화면에서 가로 넘침 없음 확인
- 작은 화면과 가로 화면에서는 세로 스크롤이 필요할 수 있음

실제 아이폰 기기 및 Safari/WebKit 엔진에서의 실행 검증은 아직 수행하지 않았습니다.
HTTPS 서비스 워커 설치와 오프라인 재실행도 실기기 검증 전입니다.

이름, 화면, 차량 그래픽과 퍼즐 배치는 이 프로젝트용으로 제작했습니다.
상용 Rush Hour 게임의 이미지나 레벨 파일을 사용하지 않았습니다.
